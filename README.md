# olha-handoff

Внутрішня сторінка передачі справ (RetroStyle Games HR).

Вміст сторінки зашифрований AES-256-GCM, ключ виводиться з пароля (PBKDF2, 250k ітерацій).
У цьому репозиторії немає ні пароля, ні тексту сторінки — тільки шифротекст.

Вихідники й збірка — у приватному репозиторії `olha-handoff-src`.
